# Astra windows

An Astra is a Codex window that `astra.py` opens on a bridge channel (`ai-bridge` skill). `look_after_astras` in `watch.py` opens, closes and reopens them; the helpers are in `astra.py`. Read this when an `ASTRA ...`, `HANDED`, `HANDOVER FAILED` or `BRIDGE STALL` line needs a decision, or when changing that code.

- **Handover**: the watcher opens an Astra for a channel only its poster is on, `HANDOVER_AFTER_SECONDS` after the last post, once per channel, when the poster has a live card in `live.json`. It skips the Master Agent's own posts: run `astra.py <work>` yourself. Channels named `astra-*` are never handed over.
- **Close**: it types `/quit` only when `why_turn_stays` and `why_job_stays` find nothing: card `Astra: <channel>`, kind Codex, `Finished` and quiet for `ASTRA_IDLE_CLOSE_SECONDS`; no unread mail; no open task of its own; no live partner on the work (a task or lane purpose naming it, waiting on the channel, or not having read it); not pinned and not `astra.py --keep`; exactly one window; a fresh `live.json`. Anything it cannot read keeps the window: a spare window is cheap, closing one mid-review is not. Every `ASTRA_CLOSE_RETRY_SECONDS` it rechecks and types again, up to `ASTRA_CLOSE_TRIES`, then leaves it open with `ASTRA NOT CLOSED`. Never `Stop-Process` an Astra.
- **Windows are found by command line** (`windows_of`: `--as astra-<channel>` or `resume <thread>`), never by the card's pid: windows opened together can carry one pid on their cards, and typing by it would close the wrong Astra. Zero or several windows: it stays.
- **Reopen**: an undelivered message for a channel the watcher closed resumes that thread from the launcher file (`resume_window`), else opens a new thread (`hand_over(..., again=True)`). It never opens a second window: a process it cannot read counts as that Astra running. At most `ASTRA_REOPENS_PER_CHANNEL` per channel and `ASTRA_REOPENS_ALL_CHANNELS` in all per `ASTRA_REOPEN_PERIOD_SECONDS`. Memory is saved before the window opens, so a dying watcher cannot open it twice.
- **Not reopened**: a window the user or a crash closed (only the watcher's own closes are in its memory). Its mail waits for `astra.py --again <work>`, or `astra.py --resume <work> <thread>` to keep the history.
- **Wake**: an idle Astra with unread mail gets its join line typed in (`wake_idle_astras`), at most every `ASTRA_WAKE_RETRY_SECONDS`.
- **Inspect**: `watch.py --astras` prints why each Astra stays open and changes nothing; `Saved/Orchestration/astra/closed.log` records every close, reopen and wake.
