# AGENTS.md

Codex and other agents: read [`CLAUDE.md`](CLAUDE.md) first. It describes this repository, how to build and test each part, the rules for changing it, and which skill to read for each task.

The skills live once, in `.claude/skills/<name>/SKILL.md`. Read the one the task touches before opening its files (a Codex has no skill tool, so open the file), and never copy a skill anywhere else. The orchestrator's own rules are `.claude/scripts/orchestration.md`; its section *Codex and other clients without Claude hooks* is for you.
